# Aged Light 4.x Changelog

## 4.0.0

**Major Changes**
- Updated to Minecraft 1.21.1
- New stone layers when mining deeper
- Added basic quest system
- New tool & armor smithing with liquids and molds
- Immersive cooking interactions
- New sprinklers, watering cans and farmland mechanics
- New tool progression system

**Other Updates**
- Various bug fixes
- Performance improvements
- Updated mods for 1.21.1 compatibility
